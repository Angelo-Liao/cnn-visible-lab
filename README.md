# CNN 看得見

繁體中文 CNN 互動教學網站。給第一次接觸神經網路的讀者，從手寫數字一步步看懂捲積、ReLU、池化、分類與 ResNet。

## 開啟網站

- [GitHub Pages 網站](https://angelo-liao.github.io/cnn-visible-lab/)
- [原 Sites 網站](https://cnn-visible-lab.angeloliao.chatgpt.site/)

這份專案是純 HTML、CSS 和 JavaScript，沒有後端、不需要 API 金鑰，也不需要建置。可直接將 `docs/` 部署到支援靜態檔案的服務。

## 本機預覽

在專案資料夾執行（需有 Python 3）：

```sh
python -m http.server 8000 --directory docs
```

接著開啟 <http://localhost:8000/>。請透過伺服器預覽；直接雙擊 HTML 會受瀏覽器讀取模型 JSON 的限制。

## GitHub Pages 更新

本 repo 使用 GitHub 的分支發布功能，來源為 `main` 分支的 `/docs`。更新 `docs/` 並推送到 `main` 後，GitHub 會重新發布；可在 repo 的 Actions 查看進度。

若複製這個 repo，請到 **Settings → Pages → Build and deployment**，選擇 **Deploy from a branch**，再選 **main** 與 **/docs**。網址中的 repo 名稱可以不同，網頁使用相對路徑載入資源。

官方說明：[設定 GitHub Pages 的發布來源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 驗證運算

需有 Node.js；不需要安裝套件：

```sh
node tests/digit-model.test.cjs
node tests/classification-weights.test.cjs
```

第一項比較 40 張測試影像的原始 ONNX 參考結果，第二項檢查 400 組分類權重變化；這些功能測試不代表所有筆跡都能辨識正確。

## 原始檔案與內容

繁體中文互動教學網站。純靜態頁面，不需要 API 或資料庫。手寫數字的預訓練權重隨網站提供，使用者不必安裝額外軟體；筆畫與辨識都在瀏覽器內處理。

- `docs/index.html`：網頁結構。
- `docs/style.css`：基礎桌面與手機版樣式。
- `docs/design.css`：依使用者指定的 Anthropic 溫暖書刊美學重新設計的視覺層。
- `docs/ink-illustration.png`：原創 AI 輔助手繪風插畫，非模型運算結果。
- `docs/math.js`：捲積、ReLU、池化與 Softmax 計算。
- `docs/app.js`：教學互動、ResNet 示範、模型年表與來源。
- `docs/digits.js`、`docs/digits.css`：手寫畫布、28 × 28 像素格與五步驟模型圖解。
- `docs/digit-model.js`：預訓練 MNIST CNN 的瀏覽器推論、筆畫裁切與置中。
- `docs/weights.js`、`docs/weights.css`：分類權重說明、16 個通道的 4 × 4 特徵與權重對照，以及單一分類權重試調。
- `docs/teaching.js`、`docs/teaching.css`：五步驟的生活例子、回到實際運算的對照與初學者版面。
- `docs/model/`：原模型轉換的權重、十個 MNIST 測試集範例、來源與授權。

## 內容邊界

本站以零基礎讀者為對象。教學順序是「這一步要解決的問題 → 生活例子 → 實際圖像操作 → 名詞與可展開的計算細節」。同一個手寫數字貫穿五步；各步使用馬賽克、小紙框、額外獎金、最高溫與餐廳評分作原創例子，並交代比喻與實際計算的對應。影片敘事參考製作者官方文字教材，詳見 `TEACHING_NOTES.md`。

ResNet 先以可操作的音量刻度 40 + 調整量說明保留輸入，再接到 4 × 4 特徵圖逐格相加與訓練動機。音量是加法比喻，不是分貝或實際網路；公式、原始 basic block 圖與訓練退化名詞放在進階展開區。修正量由訓練學來，不是逐層提供的正確答案，也不保證每一區塊都使預測更準。

「手寫數字」使用 ONNX Model Zoo 的 MNIST-12 CNN 預訓練權重，實際辨識單個 0–9 數字。第一層有 8 個 5 × 5 濾鏡，第二層有 16 個 5 × 5 濾鏡；池化依序為 2 × 2 與 3 × 3，最後由 256 個特徵算出 10 個類別分數。各步驟顯示同一次推論的實際中間結果。模型沒有在本站重新訓練，也不是 ResNet。

「基礎格子實驗」保留原本 8 × 8 影像、手工濾鏡及 A / B / C 玩具分類頭。ResNet 仍以固定陣列說明殘差相加。兩者不宣稱具備真實物件辨識能力。

手寫畫布會保留筆畫比例，縮放至 20 × 20 以內，再放到 28 × 28 影像並依筆畫重心置中；使用白色前景、黑色背景及 0–1 灰階值。空白畫布不做預測。範例按鈕使用原始測試像素，標籤不傳入模型。Softmax 比例不是測得的正確率；使用者的筆跡可能與訓練資料不同。

畫布支援滑鼠、觸控、鍵盤、清空及復原；切換教學步驟和分頁保留目前筆畫，重新整理頁面則重設。模型載入失敗會顯示重試，不顯示虛構結果。

分類頁區分濾鏡權重、分類權重、特徵值與偏置。每個分類特徵（通道及位置）對每個類別各有一個權重，實際顯示 f × w、其餘 255 項加總及偏置。教學試調只在臨時計算中將選定的一個分類權重乘上倍率，不修改學到的權重、不訓練模型，也不改動原模型的預測顯示；切換特徵、通道或類別會重設試調。此模型的分類輸入非負，因此權重正負與單項分數貢獻方向一致。

來源與影片連結在「延伸學習」分頁。影片觀看數是 2026-10-05 查核搜尋索引所得的近似紀錄，並非即時統計。

## 已執行驗證

2026-10-05：已以固定可手算範例檢查互相關方向、邊緣回應、ReLU、最大池化、奇數尺寸、步幅與補零，以及 Softmax 穩定性。Chrome 操作驗證涵蓋像素編輯、鍵盤、濾鏡切換、自動掃描、池化選取、分類偏置、ResNet 捷徑、模型分頁與影片連結。

手寫更新：40 張 MNIST 測試影像與 ONNX ReferenceEvaluator 原始推論比對，最大類別分數誤差約 5.73 × 10⁻⁶；十個內建範例皆辨識正確。這是工程驗證樣本，不代表對所有手寫輸入的準確率。另驗證空白與平移前處理、手繪 0、鍵盤繪製 1、觸控、清空復原、特徵圖選取、跨分頁保留、模型失敗重試及 375 / 768 像素寬度五步驟無水平溢出。故障測試刻意中止一次模型請求，確認其可恢復。

執行 `node tests/digit-model.test.cjs` 可重新比對已存的原始模型參考輸出。以一般靜態伺服器提供 `docs/`；直接用 `file://` 開啟會受瀏覽器 JSON 讀取限制。

權重圖解更新：`node tests/classification-weights.test.cjs` 驗證 10 個範例 × 10 個類別 × 4 種倍率，共 400 組分數分解、零權重、正負反轉、恢復原值及其他類別分數不變；另檢查零特徵與模型參數未修改。原有 40 張影像的推論比對仍通過。Chrome 已檢查類別與通道選取、格子對應、鍵盤、試調及原預測分離、重新繪圖後權重固定、基礎模式偏置說明，以及 375 / 768 像素寬度的版面；手機版所有新圖解元素皆在容器範圍內。

頁面有條件註冊 WebMCP 教學控制工具；一般瀏覽器不依賴這項功能。未在原生支援 WebMCP 的瀏覽器驗證註冊與執行，不應宣稱該整合已驗證。

零基礎敘事更新：已驗證五步驟生活例子、濾鏡運算展開區、預測、ResNet 音量十組正負/零與保留/不保留組合、重設、鍵盤滑桿、16 格相加的零修正與捷徑開關、技術圖展開、八個模型故事及三段影片學習順序。375 / 768 / 1440 像素寬度的四分頁通過水平溢出檢查並查看截圖。原始 40 張影像比對、400 組分類權重檢查，以及手寫、觸控、鍵盤、空白、復原、模型失敗重試等瀏覽器操作均重新通過。
